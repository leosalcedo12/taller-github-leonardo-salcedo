# Convertidor de Temperatura

Un script sencillo e interactivo en Python para realizar conversiones entre grados Celsius y Fahrenheit.

## Fórmulas utilizadas
* **Celsius a Fahrenheit:** `(C * 9/5) + 32`
* **Fahrenheit a Celsius:** `(F - 32) * 5/9`

## Cómo ejecutarlo
1. Asegúrate de tener instalado Python 3.x.
2. Clona el repositorio: `git clone https://github.com/tu-usuario/convertidor-temperatura.git`
3. Ejecuta el archivo: `python main.py`
